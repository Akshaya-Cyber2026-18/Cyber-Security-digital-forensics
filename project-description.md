# Cyber Security & Digital Forensics

## Project Description

This project focuses on Cyber Security and Digital Forensics.

The project aims to understand cyber security threats, detect security incidents, collect and analyze digital evidence, and support digital forensic investigations.

## Key Areas

- Cyber Security
- Digital Forensics
- Network Security
- Incident Response
- Digital Evidence Analysis

## Technologies

- Python
- C
- Linux
- Git & GitHub
- Cyber Security and Forensics Tools

## Goal

To develop practical skills in cyber security and digital forensics and learn how digital evidence can be collected, preserved, and analyzed.
